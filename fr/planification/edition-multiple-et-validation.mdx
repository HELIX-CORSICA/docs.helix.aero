# Édition multiple, attributs et validation de la mission

Trois outils accélèrent le réglage d'une mission qui contient beaucoup de tâches : régler plusieurs tâches d'un coup depuis un formulaire condensé, reporter les réglages d'une tâche sur d'autres sans tout ressaisir, et repérer d'un coup d'œil un problème de plan. Cette page couvre les trois, plus le cas du **waypoint isolé**, qui n'expose qu'un formulaire minimal.

  <Card title="Édition multiple" icon="layers">
    Sélectionnez plusieurs tâches (Ctrl/Maj-clic) : le panneau de gauche affiche un formulaire condensé qui s'applique à toute la sélection en une seule action.
  </Card>
  <Card title="Waypoint isolé" icon="map-pin">
    Un point posé seul n'a que quatre réglages : mode d'altitude, altitude, vitesse, virage.
  </Card>
  <Card title="Coller les attributs" icon="clipboard-paste">
    Copiez une tâche, puis reportez tout ou partie de ses réglages sur une ou plusieurs autres via une fenêtre à cases à cocher.
  </Card>
  <Card title="Bandeau de validation" icon="shield-check">
    Un bandeau en haut du globe signale les problèmes qui empêchent ou fragilisent le plan.
  </Card>
</CardGroup>

## Modifier plusieurs tâches à la fois

Sélectionnez plusieurs zones ou waypoints du même vol par **Ctrl-clic** (ajouter ou retirer une tâche) ou **Maj-clic** (sélectionner une plage), dans la liste des tâches du panneau de gauche ou directement sur le globe. Voir [Naviguer et sélectionner sur le globe](/fr/globe/navigation-et-selection) pour les gestes de sélection.

Dès que **deux tâches ou plus** sont sélectionnées, le panneau de gauche bascule sur un formulaire d'**édition multiple**, sous le titre **N tâches**. Rien n'est à activer manuellement.

<Note>
  Un champ **vide** (ou **Mixte** pour un menu ou un interrupteur) signifie que les tâches sélectionnées n'ont **pas la même valeur** pour ce réglage. Tant que vous ne saisissez rien dans ce champ, aucune tâche n'est modifiée pour ce réglage.
</Note>

Chaque modification s'applique **immédiatement à toute la sélection**, en une seule action : un unique **Ctrl+Z** annule le changement sur l'ensemble.

Les champs proposés dépendent de la composition de la sélection :

| Onglet | Champ | Condition d'affichage |
|---|---|---|
| **VOL** | **Mode** | Toujours. Drone et hélicoptère : AMSL, AGL, IAGL. Avion : AMSL, FGL, IAGL. Si tous les éléments suivent le télémètre : **Télémètre**. |
| **VOL** | **Altitude** | Toujours |
| **VOL** | **Tolérance AGL** | Si toutes les tâches sont des zones, corridors, segments ou waylines |
| **VOL** | **Vitesse** (unité km/h · m/s · kt au choix) | Toujours |
| **VOL** | **Virage** | Toujours, waypoints isolés compris |
| **CAPTEUR** | **Déclenchement** et **Capture en virage** | Zones, corridors, segments ou waylines, hors vol d'avion |
| **GÉOMÉTRIE** | **Recouvrement avant** et **Recouvrement latéral** | Zones, corridors ou segments uniquement : absents dès qu'une trajectoire figée fait partie de la sélection |
| **GÉOMÉTRIE** | **Gauche** et **Droite** (largeur du corridor) | Uniquement si toutes les tâches sont des corridors |
| **GÉOMÉTRIE** | **Zone stricte** | Zones, corridors, segments ou waylines, hors vol d'avion |

<Note>
  Le **capteur**, la **direction**, le **buffer**, l'**overshoot** et la **double grille** ne font pas partie de l'édition multiple : ils se règlent tâche par tâche, ou se reportent par **Coller les attributs** ; voir [Régler la couverture](/fr/planification/couverture-et-capteur).
</Note>

## Réglages d'un waypoint isolé

Un waypoint posé seul n'a pas de fauchée à couvrir : quand il est actif, le panneau n'affiche que l'onglet **VOL**, avec quatre réglages. Aucun champ de couverture n'apparaît.

| Réglage | Détail |
|---|---|
| **Mode** | Deux positions : **AGL** (hauteur au-dessus du sol sous le point) ou **AMSL** (altitude absolue). Quand le vol suit le télémètre, seul **Télémètre** est proposé. **IAGL** n'est pas proposé : ce mode suit le profil de terrain le long d'une bande, ce qui n'a pas de sens pour un point unique. |
| **Altitude** | La hauteur ou l'altitude du point, selon le mode choisi. |
| **Vitesse** | Le même champ, avec le même sélecteur d'unité, que pour une zone. |
| **Virage** | Le comportement de l'aéronef au point : **Stop & turn** (arrêt complet puis reprise) ou **Fluide** (le trajet continue sans pause ; **Adaptatif** sur drone DJI). |

## Copier/coller les attributs

Pour reporter les réglages d'une tâche sur une ou plusieurs autres sans les ressaisir :

<Steps>
  <Step title="Copier la source">
    Clic droit sur la tâche qui porte les réglages, dans la liste du panneau de gauche, puis **Copier** (ou **Ctrl+C** avec la tâche sélectionnée).
  </Step>
  <Step title="Choisir la ou les cibles">
    Clic droit sur la tâche destinataire, ou sur une multi-sélection (Ctrl-clic / Maj-clic) pour coller dans plusieurs tâches d'un coup.
  </Step>
  <Step title="Coller les attributs">
    Choisissez **Coller les attributs…** dans le menu contextuel, ou **Alt+V**. L'entrée n'apparaît que si une tâche a déjà été copiée et que la cible n'est pas la source.
  </Step>
</Steps>

La fenêtre **Coller les attributs** (résumé *Copier les attributs de … vers …*) liste, en cases à cocher regroupées par section, les réglages reportables :

| Section | Attributs |
|---|---|
| **Vol** | Altitude, Mode d'altitude, Vitesse |
| **Couverture** | Recouvrement latéral, Recouvrement frontal, Orientation, Double grille, Largeur du corridor |
| **Trajectoire** | Virage, Rayon de virage, Capture en virage, Dépassement (l'**Overshoot**), Tampon (le **Buffer AOI**) |
| **Terrain** | Tolérance AGL |

Toutes les cases sont cochées à l'ouverture ; **Tout cocher** / **Tout décocher** bascule l'ensemble. **Valider** applique en une seule action, annulable d'un seul Ctrl+Z, les attributs cochés à toutes les cibles ; **Annuler** ferme la fenêtre.

<Note>
  Seuls les attributs applicables **à la fois** à la source **et** à toutes les cibles sont proposés. Un waypoint isolé n'a que les attributs Altitude, Mode d'altitude, Vitesse et Virage ; une largeur de corridor n'apparaît que si la source et toutes les cibles sont des corridors. Si l'intersection est vide, la fenêtre affiche **Aucun attribut commun entre la source et la cible.**
</Note>

<Tip>
  Le même mécanisme existe au niveau du **vol** : copiez le vol source, faites un clic droit sur le vol destinataire dans la barre des vols, puis **Coller les attributs du vol…**. La fenêtre propose des cases **Appareil**, **Paramètres de transit**, **Retour au point de départ**, **Capteur** et **Paramètres de montée / descente**. Voir [Créer et organiser les vols](/fr/mission/vols-et-appareils).
</Tip>

## Le bandeau de validation

Quand le plan de la tâche active pose un problème, un bandeau s'affiche en haut du globe. Son titre suit la sévérité la plus grave : **Plan invalide** (erreurs), **Avertissements** ou **Informations**, avec le nombre de problèmes (par exemple *2 erreur(s)*). Le bandeau remonte notamment :

- le refus du calcul, avec le message du moteur de calcul ;
- une garde au sol insuffisante sous la trajectoire ;
- les alertes de contrôle du tracé et d'espace aérien.

Cliquez le bandeau pour ouvrir la liste détaillée ; la croix le ferme, et il réapparaît si la liste des problèmes change. Une liste vide indique **Aucun problème détecté.** Les alertes s'accumulent aussi dans le tiroir des notifications. Le détail des contrôles est dans [Alertes de sécurité et validation](/fr/qc/alertes-securite-et-validation).

<Note>
  Les champs sont bornés à la saisie (altitude de 0 à 10 000 m, recouvrement avant de 0 à 95 %, recouvrement latéral de 10 à 95 %), et la vitesse trop élevée pour l'appareil ou pour la cadence de déclenchement est ramenée au plafond avec la notification **Vitesse plafonnée**.
</Note>
