title: "Connexion et première utilisation"
description: "Se connecter à son compte Helix Aero et configurer l'application au premier lancement."
---

Helix Flight Planner s'ouvre sur un écran de démarrage qui tente de retrouver votre session, puis sur l'écran de connexion si aucune session valide n'est disponible. Cette page décrit la connexion par le navigateur, la vérification en deux étapes, la case **Se souvenir de moi** et l'assistant de configuration.

## L'écran de connexion

L'écran **Connexion** (« Utilisez votre compte Helix Aero. ») ne contient ni champ e-mail ni champ mot de passe : la saisie se fait sur la page de connexion Helix, dans votre navigateur, avec un mot de passe enregistré, Google ou Apple.

<Steps>
  <Step title="Se souvenir de moi">
    Cochez ou décochez cette option selon que vous voulez rester connecté sur ce poste (voir la section dédiée plus bas). Elle disparaît de l'écran une fois la connexion lancée.
  </Step>
  <Step title="Se connecter">
    Cliquez sur **Se connecter**. La page de connexion Helix s'ouvre dans votre navigateur par défaut.
  </Step>
  <Step title="Terminer dans le navigateur">
    L'application affiche *« Terminez la connexion dans votre navigateur. Helix se connecte tout seul ensuite. »*. Une fois la connexion validée dans le navigateur, l'application ouvre la session sans autre action de votre part.
  </Step>
</Steps>

Pendant l'attente, le bouton devient **Rouvrir la page de connexion**, utile si l'onglet a été fermé, et un lien **Annuler** abandonne la connexion en cours.

En cas de succès, l'application vérifie ensuite votre licence pour ce poste (activation de siège) avant d'ouvrir le tableau de bord. Un texte en bas du formulaire rappelle qu'en vous connectant, vous acceptez les conditions d'utilisation d'Helix.

### Vérification en deux étapes

Si votre compte demande une vérification en deux étapes, l'écran **Vérification en deux étapes** remplace le bouton de connexion. Saisissez dans **Code de vérification** le code à 6 chiffres de votre application d'authentification, ou un code de récupération, puis cliquez sur **Vérifier**. Le lien **Retour à la connexion** annule cette étape.

| Situation | Message affiché |
|---|---|
| Code erroné ou périmé | *Code incorrect ou expiré. Réessayez.* |
| Champ vide | *Saisissez le code de vérification.* |
| Trop d'essais | *Trop d'essais. Reconnectez-vous pour obtenir une nouvelle vérification.* |

### Messages d'erreur

Si la connexion échoue, un encadré orange apparaît au-dessus du bouton. Le message correspond à la cause réelle :

| Situation | Message affiché |
|---|---|
| Connexion annulée dans le navigateur | Connexion annulée dans le navigateur. |
| Connexion non terminée à temps | La connexion a expiré. Cliquez de nouveau sur « Se connecter ». |
| Impossible de préparer la connexion | Impossible de préparer la connexion sur cet ordinateur. Réessayez. |
| Identifiants refusés | Identifiants invalides. |
| Plus aucun siège machine disponible pour votre licence | Limite de postes atteinte. Aucun siège machine disponible — libérez un poste depuis le portail ou contactez votre administrateur. |
| Serveur Helix injoignable | Impossible de joindre le serveur. |
| Poste jamais activé et aucune connexion Internet | Connexion Internet requise pour activer ce poste. Connectez-vous une première fois en ligne pour enregistrer la machine sur votre licence. |
| Compte sans licence active valide pour ce poste | Licence non validée pour ce poste. Vérifiez que votre compte dispose d'une licence active, puis réessayez. |
| Session expirée | Votre session a expiré. Reconnectez-vous. |
| Toute autre cause | Échec de la connexion. Réessayez. |

<Tip>
  Les messages « Limite de postes atteinte » et « Licence non validée » ne signifient pas que vos identifiants sont faux : c'est l'activation de la licence sur ce poste qui a été refusée. Gérez vos machines enregistrées depuis le portail Helix Aero. Voir [Licence et activation du poste](/fr/compte/licence).
</Tip>

## Se souvenir de moi

La case **Se souvenir de moi**, cochée par défaut, contrôle si votre session survit à la fermeture de l'application :

- **Cochée** : la session est mémorisée de façon sécurisée dans le coffre à identifiants de votre système d'exploitation. Au prochain lancement, l'application vous reconnecte sans passer par le navigateur.
- **Décochée** : la session reste en mémoire le temps de cette utilisation. Si une session mémorisée existait sur ce poste, elle est effacée du coffre au moment de la connexion. Au prochain lancement, l'écran de connexion réapparaît.

<Note>
  Décochez cette option sur un poste partagé ou temporaire pour ne laisser aucune session persistante sur la machine.
</Note>

## Reconnexion automatique au démarrage

Au lancement, l'application affiche l'écran de démarrage, puis :

1. cherche une session mémorisée sur ce poste ;
2. la revalide auprès du serveur de licence Helix Aero, ou, sans connexion Internet, à partir de la dernière vérification enregistrée tant qu'elle a moins de 7 jours ;
3. réactive le siège machine de ce poste pour la session en cours.

Si ces étapes réussissent, vous arrivez directement sur le tableau de bord. Sinon (siège libéré depuis le portail, licence expirée ou révoquée, session absente), l'écran de connexion s'affiche.

<Warning>
  Au-delà de la période de 7 jours hors ligne, une reconnexion en ligne est nécessaire pour revalider la licence.
</Warning>

## Assistant de première utilisation

Tant que l'assistant de configuration n'a pas été complété, il s'affiche après la connexion à la place du tableau de bord. Écran **Bienvenue sur Helix Flight Planner** :

<Steps>
  <Step title="Langue">
    Choisissez la langue dans la liste (**Français** ou **English**). Le changement s'applique à toute l'interface.
  </Step>
  <Step title="Commencer">
    Cliquez sur **Commencer** pour entrer dans le tableau de bord.
  </Step>
</Steps>

<Tip>
  La langue et l'apparence restent modifiables à tout moment dans les **Réglages**. Voir [Préférences et apparence](/fr/reglages/preferences-et-apparence).
</Tip>
