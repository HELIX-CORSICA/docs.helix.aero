---
title: "Licence et activation du poste"
description: "Comprendre l'activation automatique de la licence sur chaque machine et gérer son poste."
---

Dans Helix Flight Planner, la licence est rattachée à votre **compte Helix Aero** : il n'y a aucune clé de licence à saisir dans l'application. À chaque connexion, le logiciel active, ou reconfirme, le poste sur lequel vous travaillez, en s'appuyant sur l'abonnement associé à votre compte et à votre organisation. Les droits que cette licence ouvre sont décrits dans [Offres et droits](/fr/compte/offres-et-droits).

<Tip>
  Connectez-vous avec votre compte : l'activation du poste se déclenche toute seule juste après.
</Tip>

## Comment fonctionne l'activation automatique

<Steps>
  <Step title="Connexion au compte">
    Vous vous connectez depuis l'écran de connexion, ou l'application retrouve votre session au démarrage si vous étiez déjà connecté.
  </Step>
  <Step title="Activation du poste">
    Après une authentification réussie, l'application demande au portail Helix Aero un siège de licence pour **ce poste précis**. Chaque ordinateur est reconnu par une empreinte propre à la machine ; vous n'avez rien à saisir.
  </Step>
  <Step title="Session active">
    Une fois le poste accepté, la session s'ouvre et le tableau de bord apparaît. Le même processus se répète à chaque connexion, y compris sur le même poste.
  </Step>
</Steps>

Si l'activation échoue, la connexion est bloquée et l'application affiche un message selon la raison du refus :

| Situation | Message affiché |
|---|---|
| **Limite de postes atteinte** : la licence n'a plus de siège machine disponible, ou ce poste vient d'être libéré et un délai s'applique avant sa réactivation | *« Limite de postes atteinte. Aucun siège machine disponible — libérez un poste depuis le portail ou contactez votre administrateur. »* |
| **Connexion Internet requise** : ce poste n'a encore jamais été activé et le serveur est injoignable | *« Connexion Internet requise pour activer ce poste. Connectez-vous une première fois en ligne pour enregistrer la machine sur votre licence. »* |
| **Licence non valide pour ce poste** : le compte n'a pas de licence active, ou le portail a refusé l'activation pour une raison définitive | *« Licence non validée pour ce poste. Vérifiez que votre compte dispose d'une licence active, puis réessayez. »* |

<Note>
  Ce contrôle est strict : l'application n'ouvre pas de session tant que le poste n'a pas de siège de licence confirmé. Couper le réseau ne contourne pas la vérification sur un poste qui ne l'a jamais réussie.
</Note>

## Le panneau Licence des Réglages

**Réglages → Licence** affiche l'état de la licence sur ce poste.

| Champ | Contenu |
|---|---|
| **Statut** | **Active** si la licence est valide sur ce poste, **Inactive** sinon. |
| **Type de licence** | Le mode de la licence : **En ligne** ou **Hors ligne**. |
| **Organisation** | Le domaine de l'adresse e-mail du compte. |
| **Désactiver cette machine ?** | Le bouton **Désactiver**, avec une confirmation. |

## Désactiver ce poste

<Steps>
  <Step title="Cliquer sur Désactiver">
    Les boutons **Annuler** et **Confirmer** remplacent le bouton **Désactiver**.
  </Step>
  <Step title="Confirmer">
    Cliquez sur **Confirmer** : la session de ce poste se ferme et l'application revient à l'écran de connexion.
  </Step>
</Steps>

Les sièges machine se gèrent depuis le portail Helix Aero, comme le rappelle le message *Limite de postes atteinte*.

## Se déconnecter

Le bouton **Se déconnecter** de **Réglages → Compte** ferme votre session sur ce poste et efface la session mémorisée dans le coffre à identifiants du système. Le poste reste enregistré sur votre licence : votre prochaine connexion depuis ce poste le reconnaît.

## Fonctionnalités réservées à certains droits

L'application contrôle les droits à trois endroits : le sélecteur d'appareil, les exports et envois, et l'import de plusieurs fichiers. Le calcul, l'import, l'export KML, le PDF et la vue client ne vérifient que la validité de la licence.

| Fonctionnalité | Droit contrôlé | Comportement |
|---|---|---|
| Appareils de type drone | `aircraft.drone` | Dans **Choisir un appareil**, les drones non couverts sont estompés et portent la mention *Non inclus dans votre abonnement*. |
| Appareils de type avion ou hélicoptère | `aircraft.airplane` | Même comportement ; les hélicoptères suivent le droit des avions. |
| Export `.helix` | `mission.export_helix` | Refusé avec un message *licence requise* dans la fenêtre d'export. |
| Export WPML et envoi vers DJI Pilot | `aircraft.drone` | Même message de refus. |
| Publication vers le cloud DJI | `cloud.access` | Message *Votre licence ne permet pas la publication cloud DJI.* |
| Envoi vers le FMS | `fms.access` | Message *Votre licence ne permet pas la publication FMS.* Le bouton reste visible ; le refus apparaît après la tentative. |
| Import de plusieurs fichiers de zones | `import.multi_kml` | Sans ce droit, le sélecteur n'accepte qu'un fichier. |
| Serveur MCP et CLI | `addon.mcp`, `addon.cli` | Carte **Serveur MCP (agent IA)** de **Réglages → Serveur**, état *Add-on MCP ou CLI requis*. |

Si une fonctionnalité devrait être disponible sur votre compte, contactez votre administrateur d'organisation ou le support Helix Aero pour modifier la licence.

## Mode hors ligne

L'application reste utilisable sans connexion Internet tant que le jeton de session a moins de **7 jours**. Ce jeton est renouvelé à chaque vérification de licence réussie en ligne.

- Si la dernière vérification en ligne date de moins de 7 jours, l'application démarre hors ligne et le statut de licence reste valide.
- Au-delà de 7 jours sans vérification réussie, l'application exige une reconnexion en ligne.

<Tip>
  Connectez-vous en ligne avant un déplacement sans réseau pour repartir avec une période de 7 jours complète.
</Tip>
