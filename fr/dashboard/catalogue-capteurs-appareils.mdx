Le **tableau de bord** de Helix Flight Planner regroupe trois onglets : **Missions**, **Capteurs** et **Appareils**. Cette page couvre **Capteurs** et **Appareils** : rechercher, filtrer, consulter et créer les fiches techniques que le planificateur utilise. Pour les missions, voir [Gérer ses missions](/fr/dashboard/missions).

Les capteurs (caméras, caméras thermiques, LiDAR) et les appareils (avions, hélicoptères, drones) définis ici sont ceux que vous retrouvez dans les sélecteurs **Choisir un capteur** et **Choisir un appareil** d'une mission.

## Rechercher et filtrer

Les deux onglets partagent la même barre d'outils :

- **Rechercher un capteur…** / **Rechercher un appareil…** : filtre sur le nom et le fabricant ;
- **Toutes les marques** : liste des fabricants présents dans le catalogue ;
- **Tous les types** : liste des types présents dans le catalogue ;
- le basculement **Cartes** / **Liste** ;
- le bouton **Sync** (voir plus bas) ;
- à droite, **+ Nouveau capteur** ou **+ Nouvel appareil**.

Recherche, marque et type se combinent. Sans résultat, la page affiche *Aucun résultat.* ; un catalogue vide affiche *Aucun capteur dans le catalogue.* ou *Aucun appareil dans le catalogue.*

Chaque fiche porte une **étoile** de favori. Les favoris remontent en tête de la liste, et ce choix est mémorisé sur le poste. Chaque capteur propose aussi un bouton **3D** qui ouvre l'**Aperçu 3D** de l'emprise au sol du capteur.

Quand aucune photo n'est enregistrée pour un modèle, la vignette affiche une silhouette générique.

## Fiche détail d'un capteur

Cliquez sur une carte ou une ligne pour ouvrir la fiche.

| Champ | Description |
|---|---|
| **Nom** | Nom affiché partout dans l'application. |
| **Fabricant** | Marque du capteur. |
| **Type de capteur** | **Caméra**, **Thermique** ou **LiDAR**. |
| **Système** | Système de charge utile associé, en lecture seule, s'il existe. |

Les groupes de champs suivent le type choisi.

| Type | Champs |
|---|---|
| **Caméra** et **Thermique** | **Largeur image (px)**, **Hauteur image (px)**, **Largeur capteur (mm)**, **Hauteur capteur (mm)**, **Pixel (µm)**, **Focales (mm)**, **Intervalomètre min (s)**. |
| **LiDAR** | **Champ de vision transversal (°)**, **Portée max (m)**, **Fréquence de répétition (PRR, Hz)**, **Vitesse de scan recommandée (m/s)**, **Longueur d'onde (nm)**, **Divergence du faisceau (mrad)**. |

Les **Focales (mm)** se saisissent en liste séparée par des virgules, par exemple `35,50,80`. Si **Pixel (µm)** reste vide, l'application le déduit de **Largeur capteur (mm)** divisée par **Largeur image (px)**.

<Note>
  Le type **Pushbroom** n'existe plus dans l'application : un ancien capteur pushbroom à fauchée est lu comme un LiDAR.
</Note>

<Warning>
  Tant qu'un champ requis manque, le bouton **Enregistrer** reste inactif et un encadré liste les champs manquants (*Champs requis manquants : …*). Un champ vide ou à zéro compte comme manquant.
</Warning>

Champs requis :

| Type | Champs requis |
|---|---|
| **Caméra** et **Thermique** | Nom, **Focales (mm)**, **Largeur image (px)**, **Hauteur image (px)**, **Pixel (µm)** ou les deux dimensions du capteur, **Intervalomètre min (s)**. |
| **LiDAR** | Nom, **Champ de vision transversal (°)**, **Portée max (m)**, **Fréquence de répétition (PRR, Hz)**. |

## Fiche détail d'un appareil

| Champ | Description |
|---|---|
| **Nom** | Nom affiché partout dans l'application. |
| **Type d'appareil** | **Drone**, **Avion** ou **Hélicoptère**. |
| **Type de drone** | Pour un drone : **Multicoptère**, **Voilure fixe**, **VTOL**, **Mono-rotor** ou **Autre**. |
| **Plateforme technique** | Pour un drone : **ArduPilot**, **PX4**, **Autel**, **Propriétaire** ou **Générique**. |
| **Vitesse horizontale max (m/s)** | Vitesse horizontale maximale. |
| **Indicatif** | Identifiant ou immatriculation libre. |
| **Croisière (km/h)** | Vitesse de croisière utilisée par défaut en planification. |
| **Autonomie (min)** | Durée de vol maximale. |
| **Plafond (m)** | Altitude maximale. |

Le groupe **Performances de vol** réunit **Taux de montée (m/s)**, **Taux de descente (m/s)**, **Rayon de virage min (m)** (avion et hélicoptère) et **Inclinaison max (°)** (hélicoptère). Le groupe **Limites de vol** réunit **Vitesse de décrochage (m/s)**, **Taux de virage max (°/s)**, **Montée max (m/s)**, **Descente max (m/s)**, **Garde au sol min (m)**, **Rayon d'action max (m)** et **Charge utile max (kg)**.

Un appareil du portail affiche aussi le groupe **Systèmes de charge utile**, en lecture seule : *Compatibilité capteurs gérée par le portail (systèmes de charge utile)*.

Champs requis, en plus du nom : **Type d'appareil**, **Croisière (km/h)**, **Autonomie (min)**, **Taux de montée (m/s)** et **Taux de descente (m/s)**. Un drone demande en plus **Vitesse horizontale max (m/s)** ; un avion, **Vitesse de décrochage (m/s)**.

<Note>
  La plateforme **DJI** ne se choisit pas : elle appartient aux fiches fournies par Helix Aero et à leurs copies, qui gardent la plateforme, le type et les identifiants WPML de l'original.
</Note>

## Fiches standards et personnalisées

- **Standards** : fournies par Helix Aero. Tous les champs sont en lecture seule et le bas de la fenêtre propose **Fermer**.
- **Personnalisées** : créées par vous, entièrement modifiables. Le bas de la fenêtre propose **Annuler** et **Enregistrer**.

## Créer une fiche personnalisée

<Steps>
  <Step title="Cliquer sur + Nouveau capteur ou + Nouvel appareil">
    Une fiche vide s'ouvre, avec **Caméra** comme type de capteur ou **Avion** comme type d'appareil.
  </Step>
  <Step title="Renseigner les champs">
    Nom, type, puis les champs qui apparaissent selon le type choisi.
  </Step>
  <Step title="Enregistrer">
    Le bouton reste inactif tant qu'un champ requis manque. La fiche rejoint ensuite votre catalogue et les sélecteurs de mission.
  </Step>
</Steps>

## Dupliquer un modèle standard

Pour adapter une fiche standard à votre matériel, ouvrez-la puis cliquez sur **Dupliquer comme personnalisé** (capteur) ou **Créer un nouvel appareil à partir de celui-ci** (appareil). Une fiche éditable s'ouvre avec les valeurs du modèle et un nom indiquant la copie. **Enregistrer** crée une fiche personnalisée indépendante ; le modèle d'origine ne change pas.

## Synchroniser le catalogue

Le bouton **Sync** récupère depuis votre compte les mises à jour du catalogue standard et vos fiches personnalisées. Son infobulle : *Récupérer les dernières mises à jour du catalogue*.

- Pendant l'appel, le bouton affiche **Synchronisation…**. Après un succès, il affiche **Sync (Ns)** pendant une minute avant de redevenir utilisable.
- En cas d'échec, le message *Échec de la synchronisation : …* s'affiche à côté du bouton, par exemple avec la cause *session expirée*. Le bouton reste utilisable.
- Le catalogue est aussi mis à jour à chaque connexion. Voir [Synchronisation](/fr/compte/synchronisation).

<Note>
  Une synchronisation ne vide jamais le catalogue standard : les fiches déjà présentes sur le poste sont conservées.
</Note>
