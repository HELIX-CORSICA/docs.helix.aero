Pour un drone DJI, vous pouvez envoyer le plan de vol directement vers **DJI Pilot**, soit en local, soit via le **Cloud**. Vous pouvez aussi consulter les missions du compte DJI depuis le tableau de bord.

## Avant d'envoyer

- La mission doit être **calculée** : le message *« Calculez la mission avant d'exporter. »* apparaît sinon.
- Le vol doit utiliser un **aéronef DJI**. Pour un appareil non DJI, l'envoi est grisé avec le message *« Appareil non-DJI — réservé aux drones DJI »*.

## Envoyer vers DJI Pilot

<Steps>
  <Step title="Ouvrir l'export">
    Cliquez sur **EXPORT** en haut à droite de la mission.
  </Step>
  <Step title="Choisir la destination DJI">
    Cliquez sur **Envoyer vers DJI Pilot**. Le sous-titre indique : *« Choisir le référentiel d'altitude puis Local ou Cloud »*.
  </Step>
  <Step title="Choisir le référentiel d'altitude">
    Dans **Référentiel d'altitude (DJI WPML)**, choisissez :
    - **AMSL absolu** : les altitudes sont exprimées au-dessus du niveau de la mer.
    - **Relatif au décollage** : les altitudes sont exprimées par rapport au point de décollage.
  </Step>
  <Step title="Choisir Local ou Cloud">
    - **Local** : *« Pont LAN vers DJI Pilot sur la même radiocommande »*. Le plan arrive dans DJI Pilot sur la radiocommande reliée à votre réseau local.
    - **Cloud** : *« Publie les waylines sur le portail Helix pour DJI Pilot »*. Le plan est publié sur le portail, puis récupéré par DJI Pilot.
  </Step>
  <Step title="Envoyer">
    Validez avec **Envoyer**.
  </Step>
</Steps>

### Local ou Cloud : quelle différence ?

| Option | Quand la choisir | Ce qu'il faut |
|---|---|---|
| **Local** | Vous êtes sur le terrain, avec la radiocommande DJI sur le même réseau que ce poste. | Le pont DJI Pilot doit être démarré sur ce poste. |
| **Cloud** | Vous voulez publier le plan sur le portail Helix et le retrouver depuis DJI Pilot. | Une licence qui autorise la publication cloud DJI. |

Si la licence ne le permet pas, Helix affiche : *« Votre licence ne permet pas la publication cloud DJI. »*

### Le pont DJI Pilot (Local)

Pour l'envoi **Local**, la fenêtre du pont affiche notamment **Démarrer** et **Arrêter**, l'**Adresse** à saisir dans DJI Pilot, un **Code** à 6 chiffres et la **Radiocommande** détectée.

{/* CAPTURE À FAIRE : fenêtre du pont DJI Pilot (boutons Démarrer / Arrêter, Adresse, Code, Radiocommande) */}

Dans DJI Pilot, l'adresse s'ouvre dans **Cloud Service → Open Platforms**, puis le mot de passe local est demandé.

## Missions du compte DJI (DJI CLOUD)

Le bouton **DJI CLOUD**, sur le tableau de bord, ouvre la liste des missions de votre compte DJI.

<Frame caption="Tableau de bord : bouton DJI CLOUD à côté de IMPORTER UNE MISSION">
  <img src="/images/flight-planner/dashboard.png" alt="Tableau de bord avec les boutons DJI CLOUD, IMPORTER UNE MISSION et + NOUVELLE MISSION" />
</Frame>

Si aucune mission n'est présente, le message *« Aucune mission de ce compte n'est sur le serveur DJI. »* s'affiche.

{/* CAPTURE À FAIRE : fenêtre DJI Cloud avec la liste des missions du compte DJI */}

## Waylines

La fenêtre du pont DJI Pilot comporte une rubrique **Waylines**. Les waylines sont les plans de vol tels que DJI Pilot les range dans sa bibliothèque.

{/* CAPTURE À FAIRE : liste Waylines dans la fenêtre du pont DJI Pilot */}

## Export WPML pour DJI Pilot (fichier)

Pour enregistrer un fichier plutôt que d'envoyer, ouvrez **EXPORT**, puis **Plan de vol**, et choisissez **WPML (DJI Pilot)**. Cette option n'est active que si un drone DJI est sélectionné ; sinon elle affiche *« Sélectionnez un drone DJI pour activer cet export. »*
